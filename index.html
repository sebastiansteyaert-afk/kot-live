    📱 iPhone widget
    1. Install Scriptable from the App Store (free).
    2. Tap Copy widget script below.
    3. In Scriptable, tap + and paste. Tap the title at the top, name it Kot Live, then tap Done.
    4. Tap Kot Live once and enter your name and the household code.
    5. Long-press your Home Screen → Edit → Add Widget → Scriptable, pick a size and add it. Then long-press the widget → Edit Widget → Script: Kot Live.

    Medium and large widgets have a +1 🍺 button. Lock Screen widgets work the same way. iOS refreshes widgets about every 10–20 minutes.
